# گزارش پروژه

آخرین بازبینی: 2026-10-03، نسخه سند ۱.۱. فصل ۱۸ مرجع برنامه فعال سیکل بار است: قطبیت PE1/PE2، منوهای تعداد/روشن/خاموش، تأیید و لغو، زمان‌بندی، نمایش و محل تغییر آن، متغیرهای Watch، آزمون‌ها و نقطه ادامه کار. فصل ۱۷ کتابخانه LCD و تست اولیه تاریخی را نگه می‌دارد. کاربر کارکرد نسخه جاری را روی برد تأیید کرده و مشکل سخت‌افزاری اندازه‌گیری را برطرف کرده است.

فایل اصلی گزارش `relay_on_duration_report.tex` و تنظیمات ظاهر در `report-config.tex` است. فصل‌ها در `chapters/` مستقل‌اند. فصل‌های ۱۰ تا ۱۷ به‌ترتیب مرجع توابع کاربرد، مرجع درایورها، شرح جزئی بازآرایی، مرجع کد تولیدشده، آزمون چراغ‌های عیب‌یابی، راه‌اندازی کامل ADE7880، زیرسامانه DS18B20 با شماره‌گذاری پایدار و نمایشگر کاراکتری/کلیدهای بدون جهش هستند.

فاصله خطوط، فاصله پاراگراف‌ها، فاصله ردیف جدول، رنگ‌ها و فونت‌ها همگی در `report-config.tex` متمرکز شده‌اند. مقدار فعلی فاصله خطوط ۱٫۴۵، فاصله پاراگراف ۸ پوینت و ضریب ارتفاع ردیف جدول ۱٫۳۳ است.

ساخت:

```text
xelatex -interaction=nonstopmode relay_on_duration_report.tex
xelatex -interaction=nonstopmode relay_on_duration_report.tex
```

موتور لازم XeLaTeX است. قالب از XePersian استفاده می‌کند؛ فونت ترجیحی B Nazanin و جایگزین خودکار Tahoma است. تعداد صفحه خروجی مرجع پس از هر تغییر با `pdfinfo` کنترل و در فایل وضعیت ثبت می‌شود.
